# Compatibility and versioned records

WCM uses separate version domains for source/runtime API, binary layout, configuration identity, and durable Anchor storage. They should not be conflated in deployment tooling.

## Runtime version

`WCM_VERSION_*` and `WCM_VERSION_STRING` identify the source release. Patch releases may add diagnostics, tests, or compatible behavior without changing the ABI contract.

## ABI version

`WCM_ABI_VERSION` identifies the public C structure/callback contract expected by `wcm_runtime_init()`. `wcm_runtime_config_t.struct_size` and `abi_version` are checked before a runtime accepts a configuration. A deployment must rebuild application code when the ABI version changes.

Aggregate C structure sizes are target-ABI dependent and are not persistent formats. Run `wcm_size_report` with the production compiler and flags.

## Configuration fingerprint version

`WCM_CONFIG_FINGERPRINT_VERSION` identifies the algorithm and field set used by `wcm_runtime_config_fingerprint()`. Record both the fingerprint and its version. Fingerprints from different fingerprint versions are not comparable even when the numeric value happens to match.

The fingerprint is a deterministic deployment identity aid. It is not a cryptographic signature or hostile-memory integrity mechanism.

## Anchor format

`WCM_ANCHOR_FORMAT` versions the canonical persistent Anchor image. Anchor compatibility is independent of the runtime ABI. Storage backends persist `WCM_ANCHOR_IMAGE_BYTES` generated by `wcm_anchor_encode()`, never an in-memory C structure.

A firmware upgrade that changes Anchor payload semantics remains responsible for application-level payload versioning inside the Anchor payload.

## Deployment records

A release record should carry at least runtime version, ABI version, profile, configuration fingerprint plus fingerprint version, Anchor format version, deployment ID, configuration revision, toolchain/build tag, and source archive digest. The schemas under `deploy/` encode these fields for external release systems.
